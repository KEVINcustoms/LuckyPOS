## 💡 Common Tasks

### Register a New Repair
```
1. Click "Phone Repair" button
2. Fill customer name and phone
3. Enter phone brand, model, color
4. Select repair type from dropdown
5. Add repair notes (optional but recommended)
6. Enter agreed amount (required)
7. Click "💾 Save Repair"
8. Receipt number auto-generated → Give to customer
9. Click "🧾 Print Receipt"
```

### Find a Repair
```
1. Use "Search by Name/Phone:" field
2. Type customer name or phone number
3. Click "🔍 Search"
4. Select repair from results
```

### Mark Repair Complete
```
1. Find repair in table
2. Click to select it
3. Click "✓ Mark Completed"
4. Status changes to "Completed"
```

### Print Receipt Anytime
```
1. Select repair from table
2. Click "🧾 Print Receipt"
3. Receipt prints immediately
```

## 📱 Phone Repair Workflow

```
CUSTOMER ARRIVES
        ↓
    [INTAKE FORM]
    - Customer info
    - Device details
    - Repair type
    - Problem notes
    - Agreed price
        ↓
    [SAVE REPAIR]
    - Receipt# auto-generated
    - Record stored in database
        ↓
    [PRINT RECEIPT]
    - Give to customer
    - Professional format
    - Reference number for pickup
        ↓
    [WORK ON REPAIR]
    - Technician repairs device
    - Track status as needed
        ↓
    [MARK COMPLETED]
    - Change status to "Completed"
    - Ready for pickup
        ↓
CUSTOMER RETURNS WITH RECEIPT
        ↓
    [VERIFY & DELIVER]
    - Confirm repair is completed
    - Hand over device
    - Mark as "Collected"
```
